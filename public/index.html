ElevenLabs API Key Configuration

Securely connect your ElevenLabs account without exposing secrets
1

Retrieve Your ElevenLabs API Key

Log in to your account at elevenlabs.io, go to Profile Settings → API Keys, and copy your secret API key.

2

Configure in Netlify (Production)

In your Netlify Dashboard for this site:

  1. Navigate to Site configuration → Environment variables
  2. Click Add a variable → Add a single variable
  3. Set Key to ELEVENLABS_API_KEY
  4. Paste your key into Value and save
  5. Trigger a redeploy under Deploys → Trigger deploy for the variable to take effect
3

Local Testing via Netlify CLI (Optional)

If testing locally with npx netlify dev, create a local .env file (which is git-ignored):

ELEVENLABS_API_KEY=your_actual_key_here

Never commit your .env file. VoiceCraft's .gitignore already protects it.

4

Verify Connection

Once your environment variable is set, click the button below to test the connection immediately.
